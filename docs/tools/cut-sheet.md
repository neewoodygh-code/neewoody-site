# Cut Sheet Generator (cut-sheet.html)

> Moved out of `CLAUDE.md` on 2026-11-13 to keep the always-loaded file short. Text is verbatim from CLAUDE.md; read this file when working on the area it covers, and add new detail for this area HERE, not in CLAUDE.md.

**Cut Sheet Generator (`cut-sheet.html`, built 2026-08-24, owner-directed):** the **freeform / "regular" cutlist** — distinct from the parametric wardrobe `cutlist.html`. You **type in parts** (name · length · width · qty · optional per-row board code) and it (a) computes **how many boards you need** via a guillotine shelf-packer (first-fit-decreasing, kerf-aware, grain-fixed by default with a "Plain (may rotate)" option), grouped **per board/colour code**, and (b) renders the **printable box sheet** in the exact machine-shop language reused from the wardrobe tool's Edge Band Sheet: one box per part, **length (grain) rotated on the RIGHT, width on the BOTTOM**, qty in gold in the centre, **inline-SVG edge-band ticks** (tap an edge: none→1 tick band→3 ticks double+band→clear), faint grain lines, **tap the middle to flip grain**. Purpose: the owner's own **submit-to-the-cutting-shop** sheet — a prominent **"Board / colour code" field** (e.g. "18mm Oak Melamine") identifies the colour board, **each colour prints on its own page** (`.grp{break-before:page}`), and a **fixed running print header carries the Neewoody logo + phone (+233 24 463 3464) + board code + date on every sheet** (`.print-hdr`, `@page{margin-top}` reserves the space (**26mm** as of the print-overlap fix below); `body>*:not(main)` + `.cs-hero,#inputCol,.site-footer` hidden so only `#sheetOut` prints). Standalone single file, inline CSS/JS, **navy/gold/cream** (matches the `cutlist.html` tool family; links `css/styles.css` only for nav/footer/container then overrides the `--clr-*` tokens). **Public + free, NOT gated and NO backend writes** — entries **autosave to `localStorage` (`nwd-cutsheet-v1`)**; no concierge-api/D1/Worker code touched (it only *reads* `/api/me`). mm/cm unit toggle (stored mm internally). A **"Sheet header" card** lets you switch the logo source (My business logo · My profile photo · **Upload a logo…** [custom, stored as a local data URL] · Neewoody logo · No logo) and edit the printed name/phone; a live preview shows what will print. Logged-out (the owner's own use) it defaults to **Neewoody** branding. Branding source/name/phone/customLogo live in `U` (so they travel with autosave + saved projects); `U.brandTouched` means the member customised it, so auto-adopt stops overriding their choice. Both editors drive the **same `parts[]`** so you can switch freely; a part named in list mode keeps its name, and unnamed parts (grid mode) auto-label as **`#1, #2, …`** on the output boxes (`partBox(p, fallback)`; running counter in `renderSheet`). `renderParts()` dispatches to `renderRows()` (list) or `renderGrid()` (grid) and toggles the two `#listWrap`/`#gridWrap` containers; all structural re-renders call `renderParts()`. **Reworked 2026-08-24 (owner):** the **toggle moved to a prominent top bar** (`.mode-top`, above the columns) so the entry method is chosen first. **Quick grid is a STANDALONE full-screen data-entry page** (`#qgPage`, `position:fixed;inset:0`, a body-level child so print's `body>*:not(main)` hides it): a navy top bar with **"← Done"** (`setEntryMode('list')`), the **board colour read from the Named-list tab** (`#qgCode`, read-only — *all* setup/inputs stay on the list tab per owner), a live **piece · sheet count** (`#qgCount`), and **Print/Save PDF** (prints the real cut sheet, not the overlay). Entry is organised into **"sheets" of `SHEET_SIZE` (24) boxes** (within the owner's 24–30 range); **"+ Add another sheet"** (`addSheet()`) adds a whole sheet of 24 boxes — you add sheets, not boxes. Each box mirrors the cut sheet: **length input on the RIGHT, width at the BOTTOM, quantity in the MIDDLE** of a cream board box (`.qg2`/`.qg2-frame`; right column widened to 56px so 4-digit lengths show).
