# Wardrobe cutlist (cutlist.html) and the tool-guide panel

> Moved out of `CLAUDE.md` on 2026-11-13 to keep the always-loaded file short. Text is verbatim from CLAUDE.md; read this file when working on the area it covers, and add new detail for this area HERE, not in CLAUDE.md.

**Cutlist generator:** `/cutlist.html` — parametric wardrobe cutlist for carpenters. **Print/PDF fix (2026-07-20):** the results page `#rpage` is `position:fixed; overflow-y:auto`; the old `@media print` rule targeted `.rpage` (a class that never matched the `id="rpage"` element) and never reset the fixed/overflow, so printing clipped the list to one screen (blank/partial PDF). Now: `body > *:not(main)` + `main > *:not(#rpage)` hidden, `#rpage` reset to `position:static; overflow:visible; height:auto`, and `.rhdr`/`.result-cta` (the Edit/Save/Print + CTA buttons) hidden — the full list flows across pages. **Results-page polish (2026-07-20):** (a) `#rpage` z-index was 200 but `.site-header` is `sticky; z-index:900`, so the site nav painted over the results' Edit/Save/Print bar (two bars "competing"); raised `#rpage`→1000 and `#mycl-overlay`→1100 so the results view fully takes over. (b) The brand-footer logo pointed at a non-existent `images/Neewoody_PNG_1.png` (broken icon) → repointed to `images/logo.png` (the only logo asset) with an `onerror` hide fallback; `.bf-logo` was `mix-blend-mode:screen` (expects a white logo) which made the black `logo.png` vanish on the dark footer → switched to `filter:invert(1)` so the black monogram renders white. (c) Print buttons relabelled `⎙ Print`→`⎙ Print / Save PDF` (the native print dialog is the Save-as-PDF path; no separate PDF button exists — `window.print()` IS it). **Member-bar back-nav (2026-07-20):** the logged-in `#member-bar` had only a subtle "Directory →" link and no way back to the Tools tab → added a prominent bordered **"← Tools"** link (`concierge/directory.html#tools`) beside a "Directory" link. The hero logo (now `logo.png`) is black-on-dark-green → given `filter:invert(1) brightness(1.4)` so it reads as a crisp white mark (same asset-is-a-dark-logo issue as the footer). **Edge Band Sheet — print + Ghana machine-shop convention (2026-07-20, member feedback):** the edge indicators were background-coloured `<div>` bars, which browsers **strip from printouts by default** (backgrounds don't print) — so a saved/printed cut list showed NO edgeband marks. Rebuilt each part as an **inline SVG** (vector `<line>` strokes always print, no `print-color-adjust` reliance) drawn in the local convention: **1 tick straddling an edge = edgeband that edge · 3 ticks = double the board (glue 2 up) then edgeband**. Data model: `ebState[k]` kept per-edge band booleans `{t,r,b,l}` + added a per-part **`dbl`** flag (whole board doubled → all its banded edges render 3 ticks). Helpers `ebLine`/`ebTicks`/`ebHit` in `buildEbSheet`. A legend spells out 1-tick vs 3-ticks. Also added `#rpage *{print-color-adjust:exact}` belt-and-braces. **Revised per owner feedback (2026-07-20, machine-operator clarity):** (1) the per-edge model is now a **tri-state** (`0` none · `1` band=1 tick · `2` double+band=3 ticks) — the old per-part `dbl` flag + visible **"×2 double" button were removed** (a "DOUBLE" label under each box confuses operators). **Doubling is now click-twice:** tapping an edge cycles none→band→double→none. (2) Dimensions are drawn in the **machine-shop layout — length rotated on the RIGHT of the box, width on the BOTTOM** — replacing the "W × D mm" line (that format isn't how shops write it). **(3) Grain direction (2026-07-20):** "length" = the **grain-direction** dimension, which is *usually* the longer side but the client can reverse it (drawers especially). Default length = longer dim; **tapping the middle of a box** toggles a per-part **`gflip`** flag that swaps which dimension is the length (right) vs width (bottom). Faint vertical grain lines are drawn in each box (grain runs along the length) + a legend item, and a transparent `.eb-grain` centre hit-rect handles the tap (`rerenderEbSheet`). `initEbState` normalises legacy booleans → `0/1`, drops any old `dbl`, and defaults `gflip=false`, so saved cut lists still load. **Per-section page breaks on print (2026-07-20, owner request):** each major result section starts on a fresh page so none begins part-way down a sheet. Sections that should break carry a **`.pgbreak`** class; **Parts List has no `.pgbreak`** so it shares page 1 with the alpha disclaimer (avoids wasting a page on the note alone). `@media print{.pgbreak{break-before:page;page-break-before:always}}` + `break-after:avoid` on section headers so a header never orphans at a page bottom. **Final grouping (owner, 2026-07-20):** page 1 Parts List · page 2 Cut List · page 3 **Zone Summary + Material Summary + Construction Notes together** (only Zone Summary carries `.pgbreak` to start the group; Material Summary + Construction Notes flow under it) · page 4 Edge Band Sheet.

**In-tool tutorial panel (`js/tool-guide.js`, 2026-08-23, owner-directed "mini tutorials … on a panel to the left, finally making use of the dead space"):** a self-contained, dependency-free reusable component (`window.ToolGuide.init({eyebrow,title,steps[],tips[],top,mount})`) that renders a navy/gold/cream "How to use this tool" guide (Playfair title + gold eyebrow + numbered gold step badges + a tips box; escapes content, allows `**bold**`/`<strong>`). **Two render modes, one look:** (a) **inline** (pass `mount`) → a `position:sticky` sidebar injected into a page-supplied column, collapsing to a tappable "How to use ▾" bar above the tool on `<1000px`; used by **cutlist.html**, which wraps `.calc-wrap` in a new `.tool-shell` flex (guide `#cutGuide` 240px + calculator) — the guide fills the left dead-space beside the 780px form without overlapping the full-width hero/footer. (b) **floating** (no `mount`) → a viewport-fixed left rail at `≥1300px` + a "How to use" FAB/slide-in drawer below that; used by the React **carpenter-pricing.html** SPA (no wide hero, content centered ≤700px, so a fixed rail sits clear in the left margin) — appended to `<body>` after the Babel block, independent of React state (a member without a session is redirected to login before it matters). Print-hidden via `@media print`. Cache-busted `js/tool-guide.js?v=YYYYMMDD` on both pages — **bump on change.** Content is per-page in each page's init call (cutlist: units→carcass→doors→sections→frame→results→save + edgeband/grain/print tips; pricing: overhead-first→new quote→materials/labour→tier→summary(private)→client copy→save + privacy/margin/print tips). Reusable on future tool pages.
