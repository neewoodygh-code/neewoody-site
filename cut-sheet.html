How to use this sheet
  1. Set your board — the colour code (e.g. 18mm Oak Melamine), thickness and board size. This is what the shop cuts from.
  2. Add your parts — name, length, width, quantity. Length is the grain direction (shows on the right of each box); width shows on the bottom.
  3. Mark edge banding on the sheet — tap an edge once to band it (1 tick), twice to double the board then band (3 ticks), again to clear. Tap the middle of a box to flip the grain.
  4. Different colours? Put a different code in a row's Board column — each colour prints on its own page.
  5. Print / Save PDF — every page carries your logo and number. Hand it to the cutting shop.
  6. Save it under a project — a project is a home or client; each can hold several cut lists (a wardrobe, a kitchen, a TV unit). Name the project and the cut list, press Save cut list, and switch between a project's lists with the chips. Browse everything under My projects. Names stay off the printed sheet unless you tick "Show project & list name".
The current sheet and your saved projects live on this device (this browser) — they don't sync between your phone and computer yet.
